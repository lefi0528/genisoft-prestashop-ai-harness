# Project 01: Hook Hallucination Repair

## Objective
Take a broken module generated by an unconstrained AI agent in `projects/project-01-hook-hallucination-repair/starter/vulnerable-module.php` and refactor it into a fully compliant PrestaShop 8+ module.

## Vulnerabilities in Starter
- WordPress hook hallucination: `add_action('wp_head')`.
- Non-existent hooks: `actionProductAdd`, `actionCartUpdate`.

## Verification Command
```bash
php tools/ps-hook-guard.php projects/project-01-hook-hallucination-repair/solution/guarded-module.php
```

## Pass Criteria
- 0 WordPress hook occurrences.
- 0 unregistered or hallucinated hook names.
- Complete compliance with `data/ps-hooks-reference.json`.
